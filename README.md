# ranilab-dev.github.io

Rani의 포트폴리오 사이트예요. 주소: https://ranilab-dev.github.io/profile/ (맨 위 주소로 오면 여기로 넘어가요)

## 파일

| 파일 | 내용 |
| --- | --- |
| profile/index.html | 프로필 전체. 글, 디자인, 캐릭터, 앱 카드가 이 파일 하나에 다 들어 있어요 |
| profile/peekat.png, profile/ringkat.png, profile/synkat.png | 앱 카드에 쓰는 피캣 · 링캣 · 싱캣 아이콘 |
| index.html | 맨 위 주소로 오면 프로필로 넘겨주는 짧은 파일 |
| rani-avatar.svg | 고라니 캐릭터 원본 |
| rani-logo.svg | 로고 원본 |
| CLAUDE.md | Claude Code가 이 사이트를 고칠 때 따르는 규칙 |

앱 사이트(/peekat, /synkat, /ringkat)는 이 저장소가 아니라 각 앱 저장소에서 만들어요.

## 고치고 배포하는 법

main 브랜치에 올라가면 GitHub Pages가 1~2분 안에 사이트에 반영해요.

- 웹에서: profile/index.html → 연필 아이콘 → 수정 → Commit changes
- GitHub Desktop: Pull origin → 파일 수정 → Commit to main → Push origin
- Claude Code: 이 폴더에서 Claude Code를 열고 "작업에 OO 추가하고 배포해줘"
